# Optional ESP-01 / ESP-01S Wi-Fi

The motherboard operates with no Wi-Fi module installed.

## Socket

J20 is a 2x4, 2.54 mm female socket wired as:

| Pin | Signal |
|---:|---|
| 1 | GND |
| 2 | +3V3_WIFI |
| 3 | ESP GPIO2 with 10 k pull-up to 3.3 V |
| 4 | ESP GPIO0 / programming button |
| 5 | RP2350 GPIO11 `WIFI_RX` to ESP TX |
| 6 | RP2350 GPIO10 `WIFI_TX` to ESP RX |
| 7 | EN/CH_PD, 10 k pull-up |
| 8 | RST, 10 k pull-up |

`+3V3_WIFI` is generated by a dedicated AMS1117-3.3 regulator from the 5 V
rail, followed by 10 uF plus 100 nF local decoupling. This provides the required
500 mA ESP8266 peak-current reserve. GPIO0 is pulled up and can be grounded with
SW2 for UART boot mode.

Both the original ESP-01 and ESP-01S use the same eight-pad module interface and
are supported. The original non-S module does not include all onboard strap
pull-ups, so the motherboard provides independent 10 k pull-ups on GPIO2,
GPIO0, CH_PD/EN and RST. The RP2350 UART is wired through the socket; the former
J21 external UART header is not fitted.

The antenna end of the module must face the board perimeter with at least 15 mm
of copper-free and component-free clearance. Confirm the selected module's
physical pin-1 orientation before insertion; clone boards can reverse the
socket view and some swap UART or EN ordering.

No automatic reset-to-flash circuit is fitted. Hold SW2, reset the module,
release GPIO0, then program the ESP-01 or ESP-01S through the module socket.
