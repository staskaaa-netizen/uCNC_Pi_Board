# Optional ESP-01S Wi-Fi

The motherboard operates with no Wi-Fi module installed.

## Socket

J20 is a 2x4, 2.54 mm female socket wired as:

| Pin | Signal |
|---:|---|
| 1 | GND |
| 2 | +3V3_WIFI |
| 3 | ESP GPIO2 with 10 k pull-up to 3.3 V |
| 4 | ESP GPIO0 / programming button |
| 5 | RP2350 GPIO11 `WIFI_RX` to ESP TX |
| 6 | RP2350 GPIO10 `WIFI_TX` to ESP RX |
| 7 | EN/CH_PD, 10 k pull-up |
| 8 | RST, 10 k pull-up |

`+3V3_WIFI` is generated by a dedicated AMS1117-3.3 regulator from the 5 V
rail, followed by 10 uF plus 100 nF local decoupling. The 1 A LDO provides the
required 500 mA ESP8266 peak-current reserve. GPIO0 is pulled up and can be
grounded with SW2 for UART boot mode. The former J21 external UART header has
been removed; firmware access remains through the module socket and SWD.

The antenna end of the module must face the board perimeter with at least 15 mm
of copper-free and component-free clearance. Confirm the selected ESP-01S
variant's pin order before insertion; some clones swap UART or EN pin ordering.

No automatic reset-to-flash circuit is fitted. Hold SW2, reset the module,
release GPIO0, then program the ESP-01S through the module socket.
